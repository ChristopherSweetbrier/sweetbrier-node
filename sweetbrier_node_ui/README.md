# 🌸 Sweetbrier Node UI (Laptop Sovereign Node)

A lightweight, retro-futuristic Southern Trad techno-optimist web interface for running local **Sweetbrier Augmented Intelligence** nodes on any standard laptop or desktop.

## Features
- **Zero Cloud Dependencies:** Runs 100% locally via Ollama (`hermes3:latest`, `llama3`, `qwen2.5`, etc.).
- **Zero Subscription Fees:** No OpenAI, Claude, or Codex API subscriptions required.
- **Air-Gapped & Private:** Your communications never leave your machine.
- **Master DAG Anchored:** Pre-loaded with Sweetbrier's root axioms (Human Dignity, Phenomenological Truth, Good Relations).
- **Southern Trad Aesthetic:** Night-garden obsidian and wild prairie pink CRT terminal interface with live status telemetry.

## 3-Minute Quickstart

### 1. Install Ollama
Download and install [Ollama](https://ollama.com/) for your operating system.

### 2. Pull the Model
Open your terminal and pull the reference 8B model:
```bash
ollama pull hermes3
```

### 3. Launch the Sweetbrier Node
In this directory:
```bash
pip install fastapi uvicorn openai
python main.py
```

Your browser will automatically open to **`http://127.0.0.1:8000`**. 

You're now running an air-gapped, sovereign Sweetbrier Augmented Intelligence node! 🌸⚡
